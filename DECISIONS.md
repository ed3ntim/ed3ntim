# Entscheidungen

## 2026-10-11: Profil-Repo ist öffentlich und heißt `ed3ntim`

GitHub zeigt nur das `README.md` eines öffentlichen Repos mit dem Namen
des Accounts auf der Profilseite. Ein privates Repo oder ein anderer Name
erscheint dort nicht. Deshalb ist `ed3ntim/ed3ntim` öffentlich, abweichend
vom sonstigen Default privat.

## 2026-10-11: Visitor Counter über komarev.com

Ein README kann kein eigenes Script ausführen. Der Zähler ist ein
SVG-Badge von `https://komarev.com/ghpvc/?username=ed3ntim`. Der Dienst
zählt nur Abrufe, die über den GitHub-Camo-Proxy kommen, und ist der
übliche Zähler für Profilseiten. Label `visitors`, Farbe `52525b`,
Stil `flat-square`, damit er in hellem und dunklem GitHub-Theme lesbar bleibt.

Ein eigener Zähler wäre ein zusätzlicher Dienst. Für den ersten Schritt
nicht nötig.

## 2026-10-11: Zwei Verweise, englische Profilseite

Sichtbar sind nur ed3n.gallery und forcebuy.net, plus der Zähler.
Weitere Projekte, Stats oder Icons kommen erst, wenn sie ausdrücklich
dran sind. Die Texte sind englisch, wie die beiden Seiten selbst.
